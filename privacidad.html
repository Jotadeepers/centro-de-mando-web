Política de privacidad

Última actualización: 18 de noviembre de 2026

Quién usa la aplicación

Centro de Mando es una aplicación de uso personal. Solo la utiliza su propietario, con sus propias cuentas. No hay registro abierto ni otros usuarios.

Qué datos de Google se usan

Con el permiso expreso del propietario, la aplicación accede a Google Calendar (calendar.readonly y calendar.events) y a los datos básicos de la cuenta (nombre y email) para:

  • mostrar en un único calendario los eventos de las cuentas conectadas;
  • crear, mover o borrar eventos, siempre tras una confirmación explícita del propietario.

Cómo se guardan

Los datos se almacenan en una base de datos privada controlada por el propietario. Los permisos de acceso (tokens OAuth) se guardan cifrados (AES-256) y nunca se envían al navegador. El acceso a la aplicación exige contraseña y verificación en dos pasos.

Con quién se comparten

Con nadie. Los datos de Google no se venden, no se ceden a terceros, no se usan para publicidad y no se utilizan para entrenar modelos de inteligencia artificial generales.

Uso limitado

El uso y la transferencia de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

Desde la propia aplicación («Desconectar cuenta») o en myaccount.google.com/permissions. Al desconectar una cuenta se borran sus calendarios y eventos de la base de datos de la aplicación.
